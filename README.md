# TUM 日历控制

Android 本地优先的 TUM 课程同步与个人出席规则控制器。它将私有 iCal 中的来源课程按本地规则同步到应用自建的本机专用日历和／或 Google 次级日历，并由荣耀日历显示。

当前版本：`0.2.0`（构建号 `18`，功能候选版）。完整迭代记录见 [VERSIONING.md](VERSIONING.md)。

当前状态：功能已实现，待统一真人验收。用户主动读取私有 iCal 后，来源 UID 会聚合为课程目录；新课程默认蓝色“选择出席”，可单课或批量设为绿／蓝／灰并选择生效范围。来源实例与手动校园事项会先产生两目标的差异预览，再由用户确认执行。

输出边界：本机端只使用应用创建的本地专用日历；Google 端只使用带固定所有权标记的应用次级日历，并请求最小的 `calendar.app.created` 范围。令牌仅存活在当前运行内。撤销只删除应用资料库已映射的事件，不删除日历本身或用户其他日程。

正式验收前仍需要：安装到荣耀真机、用户主动读取真实 iCal、授予本机日历权限、配置并完成 Google Android OAuth 授权、验证两目标的新增／更新／灰色截点／撤销及荣耀显示。上述每一步均需单独记录，不可由本机构建替代。

开始任何工作前后，必须阅读根目录 [AGENTS.md](AGENTS.md)。执行计划、验收结果与可复用规程只保存在本机 `.local-audit/`，不会纳入 Git 或 GitHub。
